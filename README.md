# Charmi Bandapalli — Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new repository (for example, `charmi-portfolio`) on GitHub.
2. Upload the contents of this folder to the repository root. Keep `index.html` at the root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Before publishing — quick personalisation checklist
- [ ] Review the project descriptions and make sure they reflect the current status of each project.
- [ ] Replace the generic GitHub profile links on project cards with exact repository links where available.
- [ ] Add a professional headshot if you want one (the design currently uses a typographic monogram, so no photo is required).
- [ ] Confirm the contact details, education, internship dates, and CGPA are current.
- [ ] Keep `assets/Charmi_Bandapalli_Resume.pdf` updated whenever you update your résumé.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive visual design
- `script.js` — mobile navigation interaction
- `assets/Charmi_Bandapalli_Resume.pdf` — résumé download file

The design uses Google Fonts when online; system serif/sans-serif fallbacks are provided.
